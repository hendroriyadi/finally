## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo working tree → Docker build context | Everything not excluded by `.dockerignore` is copied into a layer and persists in image history |
| host filesystem → container volume mount | The only writable, durable surface the container has |
| public port 8000 → the single uvicorn process | One process now answers both the API and the frontend; a routing mistake here is reachable by anyone who can reach the port |
| container process → host kernel | The identity the application runs as bounds the blast radius of any dependency compromise |
