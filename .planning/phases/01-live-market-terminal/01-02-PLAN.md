## Tailwind v4 theme (exact)

Tailwind v4 is CSS-first: there is no `tailwind.config.js`, the PostCSS plugin is `@tailwindcss/postcss`, and `autoprefixer` is bundled rather than installed separately. Write `frontend/app/globals.css` with exactly this content:

```css
@import "tailwindcss";

@theme {
  --color-canvas: #0d1117;
  --color-panel: #1a1a2e;
  --color-edge: #30363d;
  --color-accent: #ecad0a;
  --color-primary: #209dd7;
  --color-submit: #753991;
  --color-positive: #22c55e;
  --color-destructive: #ef4444;

  --font-sans: var(--font-inter), ui-sans-serif, system-ui, sans-serif;
}

html,
body {
  background-color: var(--color-canvas);
  color: #e6edf3;
}
```

The token is named `--color-edge`, not `--color-border`: a `--color-border` token would generate a `border-border` utility that collides confusingly with Tailwind's own `border` utility. Use `border-edge` for every muted separator.

Write `frontend/postcss.config.mjs` with exactly:

```javascript
const config = {
  plugins: {
    "@tailwindcss/postcss": {},
  },
};

export default config;
```
